# Видео сайт

Минимальная одностраничная верстка с одним видеоплеером на главном экране.

## Запуск

Откройте папку проекта и запустите локальный сервер:

```bash
cd c:/Users/user/Desktop/PEAK
python -m http.server 8000
```

После этого откройте в браузере:

```text
http://localhost:8000
```

## Что делать

Положите своё видео в папку `videos` и назовите файл `main.mp4`.

```text
PEAK/
  index.html
  style.css
  script.js
  videos/
    main.mp4
```

После этого страница будет показывать это видео автоматически.
